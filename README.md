📚 Projeto: Minha Página
📝 Sobre o projeto

Este projeto consiste na criação de um site utilizando HTML5 e CSS3, com uma estrutura simples de navegação entre cinco páginas.

A página principal possui um cabeçalho, um menu de navegação, uma área de conteúdo principal e um rodapé. O projeto também utiliza um arquivo CSS externo para a estilização das páginas.

💻 Tecnologias utilizadas
HTML5: utilizado para estruturar o conteúdo das páginas.
CSS3: utilizado para estilizar e organizar os elementos visuais do site.
🌐 Funcionalidades
Página principal com título e conteúdo.
Menu de navegação com cinco opções.
Links para acessar diferentes páginas HTML.
Cabeçalho para identificação do site.
Área principal destinada ao conteúdo.
Rodapé da página.
Arquivo CSS externo para personalização visual.
🚀 Como executar o projeto
Faça o download ou clone este repositório.
Abra a pasta do projeto no Visual Studio Code.
Acesse a pasta html.
Abra o arquivo tarefa.html no navegador.
Utilize o menu para navegar entre as páginas.
🎯 Objetivo

O objetivo deste projeto é praticar os conceitos fundamentais de desenvolvimento web, trabalhando com a estruturação de páginas HTML, estilização com CSS e criação de links para navegação entre diferentes páginas.

Projeto desenvolvido para fins educacionais.
